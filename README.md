An entry for the make.fun bounty [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59): a program that writes a two-line robot confession, one sentence owning a specific mistake and one naming the lesson and the fix, to `/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

## The apology

> I am sorry I locked Milo in the pantry overnight because I counted two tails and there were three.
>
> I have learned to count heads instead of tails before I close a door, so now I call each cat by name and wait until each one answers.
